# E02 — Média de notas positivas

Escreva uma função `media_notas_positivas(notas)` que receba uma lista de números e retorne a média somente das notas estritamente maiores que zero. Caso não exista nota válida, retorne `None`.

**Conceito avaliado:** repetição, acumuladores e condição de guarda.

**Dificuldade esperada:** inicial-intermediária. O exercício permite observar decomposição e diagnóstico de erro de acumulador.
